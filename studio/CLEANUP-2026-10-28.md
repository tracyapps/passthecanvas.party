Vector Curves node rather than the wood's normal map. A normal-only test render
restored the floor without changing its geometry, colour or roughness map.
The damaged Coat Normal connection was also disconnected. The normal texture
from the installed Poly Haven `wood_floor_worn` asset is now packed into the file.
The initial suggestion that shader Weight caused the problem was ruled out by
that test; it was the normal wiring.

**Missing photos:** the four placed images were Image Empties, which are editor
references and do not appear in final renders. They are now mesh planes with

image offsets were transferred from the original placements. Your original PNGs
were not edited. The four placed Empty objects were replaced by the planes;
their source settings are recorded in the cleanup report and the supplied backups.

**Unused items:** each file lost 14 genuinely empty collections and one abandoned
chair parent with no children. Two coffee-table materials had dead branches
pointing at nine missing old 8k image files. Those disconnected branches and
unreferenced image records were removed; the working texture branches remain.
No existing mesh object was deleted. Parent handles with children, the hidden

To brighten a fixture: select its **WARM LIGHT** child in the Outliner, open
**Light Properties**, and adjust **Power**. Values start modestly, around 22-45 W.
Increase gradually and judge in Rendered view or a render. Material Preview uses
its own preview lighting and is not proof of scene-light brightness.

The finishing collection can be disabled to compare the room before/after the
optional lights, new pendant and small prints. The table's paint finish is a
separate material on the table itself.

## Should you use the photos?

They now render successfully. **The rug is the strongest candidate to keep.**
The sofa, lockers and drying rack remain flat photographs with lighting and
perspective already baked into them. They can work for a fixed panoramic camera,
but they will not look correct from arbitrary new viewpoints, and can intersect
or overlap the native furniture.

For the dependable master, use the native 3D file. Use the photo file as a
composition experiment and consider keeping the rug while replacing the other
photo furniture with models.

In the photo file, **PHOTO CUTOUTS - rugs** and **PHOTO CUTOUTS - furniture
(experimental)** are separate collections. They are shared across all three
lighting scenes. Toggle their camera icons in the Outliner to include/exclude
them from rendering. If the camera icon column is hidden, enable it through the
Outliner filter/restriction controls. The eye icon only controls viewport display.

## Render another panoramic PNG

1. Choose **02 - Red / late afternoon** in the scene selector (or another look).
2. The active camera is already **PANO_CAM**, with **Cycles / Equirectangular**.
3. Use the top menu **Render > Render Image**. Shortcut: **F12**, or **fn + F12**
   if macOS intercepts the function key.
4. In the render window, use **Image > Save As** to save your PNG.

All three scenes are saved at **4096 x 2048**, **100%**, **128 samples**, with
denoising. Keep the 2:1 image ratio. For a quicker test use 2048 x 1024 and 32-48
samples, then restore the larger settings. A manual Render Image does not
automatically save the PNG; use Image > Save As afterward.

There is also a **START HERE - render and photo notes** text block inside each
Blender file, with the same essential commands.
